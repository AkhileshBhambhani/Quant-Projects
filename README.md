# Quant Finance Projects

This repository contains quant finance projects administered under the CQF course, since the course, these projects have been refactored, polished and enhanced to consistently improve the output.
It serves as a central index for the work, while each project folder includes its own detailed `README.md` covering objectives, methodology, implementation, and results.

## Repository Scope

The main repository is intentionally curated to include:

- `Derivatives Pricing`
- `Stock Prediction with Machine Learning via SVM Classification`
- `Portfolio Construction using Meucci's Black Litterman`

Each of these folders is self-contained and documented independently.

## Projects

- [Stock Prediction SVM](./Stock%20Prediction%20SVM/) — SVM-based directional signal for SPY
- [Meucci Black Litterman](./Meucci%20Black%20Litterman/) — Portfolio construction with Black-Litterman
- [Derivatives Pricing](./Derivatives%20Pricing/) — Derivative pricing notebook

## How To Use This Repository

1. Start from the relevant project folder.
2. Open that folder's `README.md` for project-specific context.
3. Follow any setup or execution steps documented there.

## Notes

- This top-level `README.md` is intentionally high level.
- Detailed technical explanations, assumptions, and usage instructions are maintained within each project subfolder.
